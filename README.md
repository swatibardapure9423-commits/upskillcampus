# AutoPartsHub

## 📌 Project Description
AutoPartsHub is an e-commerce web application developed to buy and manage automobile spare parts online. It provides user-friendly features for customers and admin.

## 🛠 Technologies Used
- Java (Core + JDBC)
- Oracle Database
- HTML, CSS, JavaScript

## 🚀 Features
- User Registration & Login
- Add to Cart
- Product Management
- Order Processing
- Database Integration

## 🗄 Database
- Oracle SQL
- Script available in `sql/autoparts_oracle.sql`

## ▶️ How to Run
1. Import project into Eclipse
2. Configure Oracle Database
3. Run SQL script from `sql` folder
4. Add JDBC Driver (ojdbc8.jar)
5. Run `AppServer.java`

## 📁 Project Structure
- `src/` → Java source code
- `sql/` → Database scripts
- `lib/` → JDBC driver
